# SportFit — Сучасний спортивний зал

Лендинг-сторінка для професійного фітнес-клубу SportFit. Розроблено як тестове завдання.


## Технології

- HTML5
- CSS3 (адаптивний дизайн)
- JavaScript (для інтерактивних елементів)

## Запуск

```bash
npm install
npm start
```

Або без npm:
```bash
npx serve . -l 3000
```
